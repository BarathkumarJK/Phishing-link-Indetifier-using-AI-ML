# Phishing Link Identifier using AI/ML

Phishing Link Identifier using AI/ML is a comprehensive solution aimed at identifying potentially malicious URLs and links using Artificial Intelligence and Machine Learning techniques. This project encompasses a website, a Chrome extension, and a WhatsApp bot, all working together to provide users with a seamless experience in verifying the legitimacy of URLs. This README file offers an overview of the project, its components, setup instructions, and usages.

## Introduction

The Phishing Link Identifier using AI/ML project aims to combat the increasing threats of phishing attacks by leveraging the power of Artificial Intelligence and Machine Learning. Phishing attacks often involve fraudulent URLs designed to steal sensitive information from users. This project offers an innovative approach to identify such malicious links and provide users with accurate information about their legitimacy.

## Key Features

- **AI/ML Verification:** The project employs advanced AI/ML algorithms to analyze URLs and determine whether they are potentially malicious or legitimate.
- **Website:** The project provides a user-friendly website where users can directly enter URLs for verification.
- **Chrome Extension:** The Chrome extension allows users to quickly check the legitimacy of URLs while browsing.
- **WhatsApp Bot:** The WhatsApp bot integration lets users send URLs to the bot for instant verification.
- **API Integration:** The website, Chrome extension, and WhatsApp bot communicate with the AI/ML model through an API.
- **Real-time Results:** Users receive real-time feedback on the authenticity of URLs, helping them make informed decisions.

## Components

The project consists of the following components:

1. **Website:** A user-friendly web interface where users can enter URLs to check their legitimacy.

2. **Chrome Extension:** A browser extension for Chrome that provides users with a quick way to verify URLs while browsing.

3. **WhatsApp Bot:** Integration with WhatsApp, allowing users to send URLs to the bot for verification and receive results.

4. **API:** An API that connects the AI/ML model to the website, Chrome extension, and WhatsApp bot.

## Installation

1. **Website:**
   - Clone the repository and navigate to the website directory.
   - Set up the necessary environment and dependencies as specified in the documentation.
   - Configure the API endpoint in the website code.
   - Launch the website using the preferred web server.

2. **Chrome Extension:**
   - Clone the repository and navigate to the Chrome extension directory.
   - Follow the provided instructions to package and install the Chrome extension.

3. **WhatsApp Bot:**
   - Set up the WhatsApp bot using the provided documentation.
   - Configure the API endpoint for communication with the AI/ML model.

## Usage

1. **Website:**
   - Open the website in a browser.
   - Enter the URL you want to verify and submit it.
   - Receive instant feedback on the legitimacy of the URL.

2. **Chrome Extension:**
   - Install the Chrome extension from the Chrome Web Store.
   - Click on the extension icon while browsing a website to quickly verify its legitimacy.

3. **WhatsApp Bot:**
   - Send a message with the URL to the WhatsApp bot.
   - Receive a response indicating whether the URL is potentially malicious or legitimate.
